# Gemini 生成豆包 PPT 包上传清单

将 `上传资料` 里的文件上传给 Gemini，让 Gemini 产出“给豆包的 PPT 生成包”。如果网页端单次上传数量有限，按以下优先级上传。

1. `01_教师要求与评分`
   - `2026数据库课程设计任务书.doc`
   - `数据库课程设计报告模板.doc`
   - `txt中提到的打分依据.png`
   - `关于课程设计，群聊中的重要问题答疑.txt`

2. `02_报告与阶段文档`
   - `需求分析word正式版.doc`
   - `需求分析.md`
   - `概要设计.md`
   - `详细设计.md`
   - `当前报告草稿_仅供内容覆盖参考.docx`

3. `03_当前PPT草稿`
   - `当前PPT草稿_仅供覆盖范围参考.pptx`
   - `S01.png` 到 `S12.png`
   - `content_report.md`
   - `design_spec.md`
   - `slide_blueprint.md`
   - `spec_lock.md`

4. `04_界面截图与图表素材`
   - 全部真实界面截图。
   - 已生成的功能结构、ER、流程、SQL 对象、NL2SQL、安全链路、后台架构和演示路线图。

5. `05_代码与数据库证据`
   - `README.md`
   - `schema.sql`
   - `pom.xml`
   - `data.sql`
   - 数据库连接、DAO、AI、搜索、版本、扫描、主界面相关 Java 文件。

6. `06_筛选TXT原文`
   - `重要TXT原文合并_只删无关噪声.txt`

上传后，把 `00_给Gemini的提示词_生成豆包PPT交付包.md` 全文复制给 Gemini。
