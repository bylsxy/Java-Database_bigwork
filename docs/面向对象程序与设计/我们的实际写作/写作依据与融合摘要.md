## 4. JAR 双击无反应说明

- 命令行启动日志显示目标 JAR 能启动：HikariCP 连接池启动成功，主界面初始化完成，应用程序启动成功。
- 双击无反应常见原因是 Windows 用 `javaw.exe` 启动，错误不会显示；也可能是 `.jar` 文件关联到了旧 Java，或缺少 PostgreSQL 数据库。
- 当前项目按 Java 21 编译，JDK 21 及以上可运行；本机 `.jar` 已关联到 JDK 26，正常验收可双击打开，命令行只作为排错方式：`java -jar 面向对象程序设计实践目标代码.JAR`。

## 5. 本次稳定性修订依据

- AI 默认节点从源码和数据库中移除，统一改为本机私有 fallback 配置列表。
- 密钥和端点只保存在用户本机配置文件中，不写入源码、README、课程报告和源代码 ZIP。
- 设置页模型由兼容 `/models` 接口获取后下拉选择，同时支持失败降级和熔断，避免单一端点临场不可用。
- 首次向导的设置链接已真正打开设置页，选择长路径或大目录后内容区可滚动，底部确定/取消按钮保持可见。
- AI 扫描不随每次启动自动触发；切换目录会取消旧扫描，并且待识别 SQL 限定在当前根目录。
- 单次 AI 识别上限改为设置项，默认 `100(max)`，界面中凡是批处理上限都按 `N(max)` 显示；主界面提供停止扫描和清理 AI 标签功能，清理前显示数据位置、大小和保留浪费。

## 6. 最终重新提交前新增亮点

- 主界面新增“补打 AI 标签”，用于自动识别遗漏、子目录刚同步或界面未刷新后的手动补救，不需要重启软件。
- 设置页改为单实例窗口，重复点击只置顶已有设置页，避免两个设置窗口互相覆盖配置。
- 新增数据库连接与初始化向导：未连接 PostgreSQL 时主界面仍可打开，向导提供 PostgreSQL 官方下载链接、连接检测、本机配置保存、一键创建数据库和执行内置 `schema.sql`。
- `sql/schema.sql` 和 `sql/data.sql` 已打进 JAR，别人只拿到目标 JAR 也能由向导读取内置脚本完成初始化。
- 数据库不可用时增加离线浏览降级，基础目录浏览、缩略图、查看和幻灯片仍可体验；标签、搜索、AI 识别和版本历史保持数据库未连接提示。
- 报告新增“本组创新点总览”和“数据库向导”截图，避免老师只看到基础题目功能而忽略最终版本的适配设计。
