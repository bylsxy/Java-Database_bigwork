# 实验4答辩演示提纲

1. 说明本系统承接实验1-3，正式名称统一为“基于PostgreSQL的数字图像集成管理系统”。
2. 启动目标JAR，展示主界面的目录树、缩略图区域、扫描状态和数据库连接状态。
3. 切换到数据库连接与初始化向导，说明无PostgreSQL时也能打开主界面，并可一键执行内置 `schema.sql`。
4. 展示批量重命名对话框，重点解释预览、事务、日志和失败回滚。
5. 展示设置页，说明AI Key不写死、模型从 `/models` 获取、扫描上限可配置。
6. 展示图片查看、幻灯片播放、图片编辑器和版本历史，说明这些不是停留在设计图，而是已经有FXML和Controller实现。
7. 打开 `experiment4-mvn-package.log`，定位 `BUILD SUCCESS`；打开源码快照说明可复查当前实现。
8. 如果现场没有数据库或AI Key，按离线浏览降级路线演示，避免答辩现场被外部环境卡住。
